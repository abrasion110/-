# راهنمای جامع ابزار تفکیک لایه‌های تصویر (Termux Art)

این پروژه یک اسکریپت تعاملی پایتون برای تفکیک، ادغام و مدیریت لایه‌های رنگی تصویر بر اساس الگوریتم Median Cut است.

## پیش‌نیازها و نصب
برای نصب وابستگی‌ها در ترموکس دستورات زیر را اجرا کنید:
```bash
pkg update && pkg install -y python git termux-api
pip install pillow numpy
```

## نحوه استفاده
۱. تصویر مورد نظر خود را با نام `image.png` در مسیر قرار دهید:
```bash
/sdcard/termux-art/image.png
```

۲. اجرا کردن اسکریپت:
```bash
python dto-interactive.py
```

۳. مراحل تعاملی:
- **تعداد رنگ‌ها:** تعداد لایه‌های مورد نظر را وارد کنید (مثلاً ۶).
- **انتخاب منو:**
  - **حالت ۱:** خروجی گرفتن از تمام لایه‌ها به‌صورت فایل‌های PNG جداگانه با پس‌زمینه شفاف.
  - **حالت ۲:** ادغام لایه‌های دلخواه (مثلاً ۲ و ۳) با یک رنگ RGB سفارشی.
  - **حالت ۳:** حذف لایه‌های اضافی و خروجی گرفتن از مابقی لایه‌ها.

خروجی‌ها درون پوشه `layers/` با کیفیت high-DPI ذخیره می‌شوند.
